# 设置界面修改计划

## 一、需求概述
修改设置界面，添加保存按钮，修改开机自启动的交互逻辑。

## 二、修改内容

### 1. 修改按钮布局
将底部的单个"关闭"按钮改为水平布局，包含"保存"和"关闭"两个按钮：
- 右侧添加"保存"按钮
- 左侧保留"关闭"按钮

### 2. 修改开机自启动交互
- 勾选/取消勾选时，弹出确认提示（确认开启/确认关闭），但**不立即执行**
- 用户点击"保存"按钮时，才根据勾选状态执行自启动设置
- 用户点击"关闭"按钮时，不保存任何设置，直接关闭

### 3. 新增保存功能
- 点击"保存"按钮时，检查开机自启动勾选状态
- 如果勾选：添加自启动注册表项
- 如果未勾选：删除自启动注册表项
- 弹出保存成功提示

#### 修改 init_ui() 方法
```python
def init_ui(self):
    # 窗口设置
    self.setWindowTitle("设置")
    self.resize(400, 300)
    self.setWindowFlags(Qt.Dialog | Qt.WindowCloseButtonHint)
    
    # 布局
    layout = QVBoxLayout()
    
    # 更改姓名按钮
    change_name_btn = QPushButton("更改姓名")
    change_name_btn.clicked.connect(self.change_name)
    layout.addWidget(change_name_btn)
    
    # 开机自启动勾选框
    self.autostart_checkbox = QCheckBox("开机自启动")
    self.autostart_checkbox.stateChanged.connect(self.toggle_autostart)
    self.load_autostart_status()
    layout.addWidget(self.autostart_checkbox)
    
    layout.addStretch()
    
    # 底部按钮区域
    button_layout = QHBoxLayout()
    button_layout.addStretch()
    
    # 关闭按钮
    close_btn = QPushButton("关闭")
    close_btn.clicked.connect(self.reject)
    button_layout.addWidget(close_btn)
    
    # 保存按钮
    save_btn = QPushButton("保存")
    save_btn.clicked.connect(self.save_settings)
    button_layout.addWidget(save_btn)
    
    layout.addLayout(button_layout)
    
    self.setLayout(layout)
```

#### 修改 toggle_autostart() 方法
只显示确认提示，不执行实际操作：
```python
def toggle_autostart(self, state):
    # 仅显示确认提示，不执行实际操作
    action = "开启" if state == Qt.Checked else "关闭"
    reply = QMessageBox.question(
        self, "确认", 
        f"确认{action}开机自启动吗？",
        QMessageBox.Yes | QMessageBox.No
    )
    if reply != QMessageBox.Yes:
        self.autostart_checkbox.blockSignals(True)
        self.autostart_checkbox.setChecked(not (state == Qt.Checked))
        self.autostart_checkbox.blockSignals(False)
```

#### 新增 save_settings() 方法
```python
def save_settings(self):
    # 保存开机自启动设置
    try:
        key = winreg.OpenKey(winreg.HKEY_CURRENT_USER, 
                            r"Software\Microsoft\Windows\CurrentVersion\Run", 
                            0, winreg.KEY_SET_VALUE)
        if self.autostart_checkbox.isChecked():
            # 添加自启动项
            script_path = Path(__file__).parent.parent / "start.py"
            python_exe = sys.executable
            command = f'"{python_exe}" "{script_path}"'
            winreg.SetValueEx(key, "DesktopPet", 0, winreg.REG_SZ, command)
        else:
            # 删除自启动项
            try:
                winreg.DeleteValue(key, "DesktopPet")
            except WindowsError:
                pass
        winreg.CloseKey(key)
        QMessageBox.information(self, "成功", "设置已保存！")
        self.accept()
    except Exception as e:
        QMessageBox.critical(self, "错误", f"保存失败：{str(e)}")
```

## 四、修改说明
1. 开机自启动的注册表操作移到"保存"按钮点击时执行
2. 勾选/取消勾选时只弹出确认提示，不实际修改注册表
3. "关闭"按钮使用 `reject()` 直接关闭，不保存
4. "保存"按钮执行实际操作并显示成功提示
