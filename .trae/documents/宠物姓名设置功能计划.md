## 3. 实现方案

### 3.1 创建启动脚本 start.py（项目根目录）
**目的**：作为程序入口，先检查 basic.txt，然后决定运行哪个程序

功能：
1. 检查 basic.txt 文件是否存在及内容
2. 如果文件不存在或内容为空：
   - 运行 project/name.py
   - 等待 name.py 完成
   - 再次检查 basic.txt
3. 如果 basic.txt 有内容，运行 project/main.py

### 3.2 重写 project/name.py
**目的**：创建宠物姓名输入界面

UI 设计：
- 窗口标题："宠物姓名设置"
- 窗口大小：400×200 像素（适当大小）
- 居中显示

界面元素：
1. 标签："请输入宠物姓名："
2. 行编辑框（QLineEdit）：用于输入姓名
3. 水平布局：
   - 取消按钮（QPushButton）：文本"取消"
   - 确认按钮（QPushButton）：文本"确认"

功能逻辑：
1. 点击"取消"：
   - 退出程序（sys.exit）
2. 点击"确认"：
   - 检查输入是否为空
   - 若为空：弹出警告"姓名不能为空！"
   - 若不为空：
     - 弹出确认对话框："确认名字为【XX】吗？"
     - 若用户选择"否"：返回继续编辑
     - 若用户选择"是"：
       - 将姓名写入 basic.txt（格式：第一行是姓名）
       - 关闭当前窗口
       - 启动 project/main.py
       - 退出 name.py

### 3.3 修改 project/main.py
**目的**：从 basic.txt 读取姓名并在菜单中显示

修改内容：

#### 3.3.1 添加姓名读取功能（第11-22行）
在 `__init__` 方法中添加：
```python
self.pet_name = ""
self.load_pet_name()
```

添加新方法 `load_pet_name()`：
```python
def load_pet_name(self):
    basic_path = Path(__file__).parent.parent / "basic.txt"
    if basic_path.exists():
        with open(basic_path, 'r', encoding='utf-8') as f:
            lines = f.readlines()
            if lines:
                self.pet_name = lines[0].strip()
```

#### 3.3.2 修改右键菜单（第106-131行）
修改 `show_context_menu()` 方法：
- 将【名字】选项的文本改为从文件读取的姓名
- 如果读取到姓名，显示为"XX的档案"
- 如果没有读到姓名，回退到"名字"

#### 3.3.3 修改 show_name 方法（第136-137行）
修改为显示具体姓名：
```python
def show_name(self):
    if self.pet_name:
        QMessageBox.information(self, "名字", f"宠物名字：{self.pet_name}")
    else:
        QMessageBox.information(self, "名字", "宠物名字：未设置")
```
