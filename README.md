# 桌面宠物使用说明

## 程序入口
运行 `start.py` 即可启动桌面宠物程序

## 首次运行
1. 运行 `start.py`
2. 如果 basic.txt 为空，会弹出"宠物姓名设置"窗口
3. 输入宠物姓名（不能为空）
4. 点击"确认"后，会再次确认
5. 确认后，姓名会保存到 basic.txt，并自动启动桌面宠物

## 后续运行
1. 运行 `start.py`
2. 程序会自动检查 basic.txt
3. 如果已有姓名，直接启动桌面宠物

## 功能说明

### 桌面宠物操作
- **拖动**：鼠标左键长按并拖动宠物
- **右键菜单**：
  - 【名字】：显示宠物档案（如果有姓名）
  - 【情绪】：显示宠物情绪
  - 【状态】：显示宠物状态
  - 【设置】：设置功能（开发中）
  - 【捉迷藏】：隐藏宠物
  - 【再见】：退出程序

### 系统托盘
- 宠物隐藏后，可通过托盘图标恢复显示
- 托盘菜单包含：
  - 【设置】
  - 【隐藏宠物】
  - 【退出】

## 文件结构
```
the pet\
├── start.py          # 程序入口
├── basic.txt         # 宠物信息存储
├── requirements.txt  # 依赖声明
├── project\
│   ├── main.py      # 桌面宠物主程序
│   └── name.py      # 姓名设置程序
└── assets\
    └── idle\        # 动画帧图片
```

## 依赖安装
```bash
pip install -r requirements.txt
```

## 注意事项
- 确保 assets/idle 文件夹中有 PNG 格式的帧图
- 姓名保存在 basic.txt 文件中，可以手动编辑
- 程序需要 Python 3.7+
